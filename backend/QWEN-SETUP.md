# Qwen عبر الخدمات الموجودة

تمت إضافة أولوية Qwen للمحادثة /api/chat، مسار الأدوات /api/agent، وتجهيز أوامر التقويم والمهام وخدمات الجهاز. لا تنفذ طبقة النموذج الأدوات بنفسها؛ تبقى أدوات التنفيذ والتحقق والتأكيد كما هي. البحث والتحليل والمحاضرات تحتفظ بإعداداتها الحالية في هذه المرحلة.

الأسماء: Groq qwen/qwen3.8-27b، وCerebras qwen-3.8-27b. يستخدم المفتاح الموجود لكل مزود، ثم يجرب نماذج الحساب الأصلية عند تعطل النموذج. لا يضيف OpenRouter ولا يشحن أرصدة ولا يغير خطة حساب. الاستخدام يخضع للحصة والفوترة الحالية لدى المزود، وليس حصة مجانية جديدة بلا حدود.

النشر: backend على Render فقط. لا حاجة لمفتاح أو SQL جديد. متغير QWEN_ENABLED=false يلغي أولوية Qwen ويعيد ترتيب النماذج السابق؛ بعد تغييره أعد نشر الخادم. إعدادا CEREBRAS_MODEL وGROQ_MODELS يظلان قائمة البدائل الأصلية. استجابة /api/chat تشمل provider وmodel الفعليين لتشخيص المصدر.

التحقق في 18 نوفمبر 2026: نجحت على Groq محادثة عربية ومسودة موعد اصطناعية بعد 15 دقيقة لمدة 30 دقيقة واختيار أداة قراءة وهمية. لم تحفظ أحداث ولم تنفذ أدوات. Cerebras رفض الاختبار بحالة 402؛ وجود النموذج في قائمة الحساب لا يضمن أن حصة التوليد أو الرصيد متاحان. لا حاجة لتمويله لإنجاح Groq.

npm.cmd run test:models لاختبارات ترتيب النماذج والبدائل والحفاظ على طلبات الأدوات. scripts/verify-qwen-live.js اختبار اختياري اصطناعي عبر المزودين ويستهلك حصة API؛ يسجل نتيجة كل مزود بشكل مستقل.

# إعداد الصوت

انشر تغييرات backend على Render وتغييرات frontend على Vercel معًا. يلزم GROQ_API_KEY في Render فقط؛ لا تضعه في الواجهة. لا توجد migration جديدة.

على الجوال اختر «تحدث بالضغط»، وسجّل الطلب كاملًا ثم أنهِ التسجيل. يرسل التسجيل إلى Groq Whisper للتفريغ، ثم يظهر نص قابل للتحرير. أرسل النص بعد مراجعته؛ الموعد أو المهمة يحتاجان تأكيد حفظ منفصلًا.

الحد 90 ثانية أو 8MB. بلوغ الحد يلغي التسجيل دون رفعه. الإلغاء وإخفاء الصفحة يوقفان المسارات الصوتية؛ العودة لا تعيد تشغيل المايك. الخادم يعالج الصوت في الذاكرة ولا يحفظه على القرص. طلب التفريغ محمي بتسجيل الدخول.

نداء الاسم ما زال خيارًا، لكن دعم التعرف المستمر يختلف بين المتصفحات. أزيل الإيقاف القسري للكلام المؤقت، وحُدّت استعادة الانقطاعات السريعة بمحاولة واحدة. يتوقف بعدها برسالة بدل التكرار بلا نهاية. مُنسق ملكية المايك يمنع تنافس أدوات التبويب نفسه.

التحقق: npm.cmd run test:wake في frontend، وnpm.cmd run test:speech في backend. اختبار المتصفح scripts/verify-recorded-voice-ui.js يحاكي التسجيل وخدمات التنفيذ؛ يتحقق من بقاء stream واحد خلال الوقفات، المراجعة قبل التخطيط، والإغلاق عند الإلغاء وإخفاء الصفحة، وعدم الاستئناف عند العودة.

نجح scripts/verify-speech-live.js مع صوت اصطناعي عربي وإنجليزي عبر الخدمة الفعلية. لا يختبر هذا ميكروفون هاتف المستخدم أو دقة نداء الاسم عليه. الاختبارات لا تحفظ مواعيد أو ترسل Telegram.

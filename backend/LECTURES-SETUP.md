# مساحة المحاضرات

## النشر
انشر backend على Render (npm install يشمل fflate) والواجهة على Vercel. لا تحتاج قاعدة بيانات أو SQL جديدًا. يلزم GEMINI_API_KEY وGROQ_API_KEY الموجودان في الخادم. لا ترسل المفاتيح للمحادثة أو تضعها في Vite.

النماذج الافتراضية: Gemini gemini-3.5-flash للقراءة والمراجعة، وGroq openai/gpt-oss-120b للشرح والتلخيص والأسئلة. يمكن تحديد LECTURE_GEMINI_MODEL وLECTURE_GROQ_MODEL في Render. يجب أن يدعم نموذج Gemini الميديا وJSON، ونموذج Groq JSON. لا يوجد fallback صامت إلى نموذج واحد؛ فشل أي مرحلة يظهر خطأ.

## الاستخدام
زر «المحاضرات» في الشريط العلوي ← اختر الملف ← وافق على إرسال المحتوى إلى المزودين ← اشرح ولخص. الواجهة تعرض مرحلة القراءة، ثم الشرح، ثم المراجعة. راجع الملخص والشرح والأسئلة مع الإجابات وملاحظات المراجع والنص المستخرج. يمكن تنزيل جميع الأقسام والمراجع في aql-lecture.md.

## الحدود والخصوصية
- PDF وPPTX وتسجيلات MP3/M4A/WAV/OGG/MP4/WebM؛ 12MB للملف في هذه النسخة. ليست خدمة رفع تسجيلات غير محدودة؛ قسّم التسجيلات الأكبر أو اضغطها قبل الرفع.
- PPTX: نص الشرائح فقط، دون الصور/المخططات/ملاحظات المتحدث. صدّره PDF لتضمين الرسومات. ملفات PPT القديمة غير مدعومة؛ حوّلها إلى PPTX أو PDF.
- PDF والميديا تُرسل إلى Gemini؛ النص المستخرج يرسل إلى Groq، ثم يعود إلى Gemini مع المسودة للمراجعة. PPTX يُفك محليًا ويرسل نصه فقط. موافقة صريحة قبل الإرسال.
- مراجع صفحات PDF وتوقيت الميديا مستخرجة بالنموذج وقد تكون تقريبية؛ التحقق النهائي من الملف الأصلي. المراجع ليست روابط تنقّل داخل الملف.
- النموذجان مختلفان فعلًا، لكن المراجع يعتمد على النص المستخرج؛ ليس تحققًا مستقلًا كاملًا من أصل التسجيل، واتفاق النماذج لا يثبت الصحة.
- لا تخزين للرفع أو النتائج في قرص الخادم أو قاعدة البيانات. المعالجة بالذاكرة، والنتائج تبقى في التبويب حتى التحديث أو اختيار ملف آخر. سياسات مزودي الذكاء مستقلة؛ لا تدّعي حذفًا من أنظمتهم.
- حد 80 وحدة مصدر و60000 حرف. الاستخراج غير الكامل يُرفض بدل إخفاء الاقتطاع. فك PPTX محدود الحجم لتجنب ضغط الأرشيفات الخبيثة.
- دخول مطلوب، تحليل واحد للحساب، وثلاث عمليات على الأكثر لكل عملية خادم. إغلاق النافذة أو الإلغاء يقطع طلب المتصفح ويطلب إيقاف الطلبات الخلفية؛ قد لا يلغي تكلفة طلب وصل بالفعل للمزود.

## التحقق
npm.cmd run test:lectures: الأنواع والحدود، فك PowerPoint، ترتيب النماذج، عدم نجاح جزئي مضلل، دخول المستخدم ونتيجة NDJSON. scripts/verify-lecture-ui.js: موافقة قبل الرفع، عرض النتيجة والتبويبات على جوال بخدمات محاكاة. scripts/verify-lecture-live.js [pdf|audio]: اختبارات اصطناعية اختيارية عبر المزودين الحقيقيين؛ تستهلك حصة API ولا ترفع ملفات شخصية.

التحقق الفعلي في 17 نوفمبر 2026: نجحت ملفات اصطناعية PPTX وPDF وWAV عبر Groq + Gemini. الفيديو مدعوم في مسار الرفع والميديا واختباره الآلي يحاكي المزود؛ لم يُجرَ اختبار فيديو فعلي عبر المزودين في هذه الجولة.

## تنزيل المحاضرة
يمكن اختيار PDF (الافتراضي) أو Word بصيغة DOCX أو Markdown. جميع الصيغ تتضمن الملخص والشرح والأسئلة والإجابات وملاحظات المراجع والتحذيرات وأسماء النماذج والنص المستخرج. التصدير يتطلب تسجيل الدخول، ولا يعيد استدعاء نماذج الذكاء أو يحفظ المحاضرة. يحتاج نشر الواجهة والخادم. تم فحص PDF العربي بصريًا وفحص بنية ومحتوى DOCX آليًا؛ renderer الخاص بـDOCX لم يعمل لعدم تثبيت LibreOffice على جهاز الاختبار.
